# OnePledge brand: "Notary at midnight"

OnePledge replaces a ritual of trust: liens, notaries, sealed registers. The brand borrows that language instead of crypto neon:
- Midnight ink for the ground.
- Ledger paper for the words.
- One colour of sealing wax, reserved for the moment a pledge is made.

The live version of this guide is at [onepledge.vercel.app/brand](https://onepledge.vercel.app/brand).

## Signature: the Seal

A steel notary die, engraved with a guilloché rosette and a numeral one. On the landing page it moves through one scroll-scrubbed scene:
1. It presses a wax impression onto an invoice.
2. It recoils from the duplicate.
3. The invoice's opaque tag rises into the public set.

It is the one loud element. Everything around it stays quiet. The scene is generated in code (`web/src/scenes/seal/`), and the choreography is a pure function of scroll progress.

## Mark

| File | Use |
|---|---|
| `mark-wax.svg` | Primary: wax disc, ink ring and numeral |
| `mark-ink.svg` | On dark grounds where wax would compete |
| `mark-paper.svg` | On light grounds |
| `mark-small.svg`, `favicon.svg`, `favicon-32.png` | 16–32 px: the ring is dropped |
| `icon-192.png`, `icon-512.png`, `maskable-512.png`, `apple-touch-icon.png` | App icons |

- **Clear space:** keep space around the mark equal to half its diameter.
- **Don't:**
  - recolour the numeral wax on a wax disc
  - add effects
  - set the numeral in a font (it is a drawn path)

## Wordmark and lockups

**One**_Pledge_: "One" upright, "Pledge" in italic, so the promise word leans. The wordmark is outlined from Fraunces (600 upright, 500 italic, optical size 72), so the files need no font.

| File | Use |
|---|---|
| `wordmark.svg` / `wordmark-ink.svg` | Paper or ink wordmark |
| `lockup-horizontal.svg` | Mark + wordmark on ink, clear space built in |
| `lockup-stacked.svg` | Stacked on paper |

## Colour

Near-monochrome, with wax as the only accent. Values and roles are in [`tokens.json`](tokens.json), generated from `web/src/brand/tokens.ts`.

| Token | Hex | Role |
|---|---|---|
| ink | `#0B0D12` | Ground |
| ink2 | `#12151C` | Raised surfaces |
| ink3 | `#1A1E27` | Pressed or hovered surfaces |
| rule | `#2A2F3A` | Hairlines |
| paper | `#EDE6D6` | Primary type, invoice sheets |
| paperDim | `#A9A396` | Secondary type (7.6:1 on ink) |
| wax | `#E0452B` | The accent: marks, fills with ink text (4.7:1 on ink). Paper text on wax fails contrast; use ink. |
| waxLit | `#F0664A` | Wax for small text and links on ink |

## Type

| Role | Face | Rules |
|---|---|---|
| Display | Fraunces Variable | Headlines only. Italic marks the one word that carries the promise ("*One pledge.*", "*refused.*"). Tight tracking at large sizes. |
| Body | Inter Variable | Paragraphs and interface. |
| Utility | JetBrains Mono Variable | KSeF numbers, tags, hashes, block heights, and labels in capitals with open tracking. |

All three are OFL licensed. The licences are included here as `OFL-*.txt`. On the site they are self-hosted woff2 files.

## Pattern

`guilloche.svg`: woven rings and hypotrochoid rosettes, the engraved line work of banknotes and certificates. It is generated by `web/src/brand/guilloche.ts`, the same code that engraves the 3D seal.

## Motion

- **Easing:** out `cubic-bezier(0.16, 1, 0.3, 1)`; state changes `cubic-bezier(0.65, 0, 0.35, 1)`.
- **One choreographed moment:** the seal scene.
- **Page changes:** an ink wipe from the point you clicked (View Transitions).
- **Buttons:** press like a stamp.
- **Reduced motion:** illustrated beats and instant changes.

## Imagery

- `seal-render.png`: a frame of the real scene at the moment of pledge.
- `og.png`: the link preview (1200 × 630).

The KSeF number on the invoice is synthetic and labelled as such. The tags in the public set are real registry v2 tags on Midnight Preprod.

## Regenerating

```bash
cd web
npm run brand:tokens                         # tokens.css + docs/brand/tokens.json
python3 scripts/brand/outline_wordmark.py    # wordmark outlines (needs fontTools + brotli)
npm run brand:svg                            # marks, wordmark, lockups, pattern, favicon.svg
npm run build && npx vite preview --port 4318 &
npm run brand:raster                         # PNG icons, seal render, og.png, site.webmanifest
```
